## 3. 辅助函数

| 函数 | 说明 |
|------|------|
| `hasBuff/hasDebuff` | buff/debuff 检测（onlyCheckSelfHot 控制） |

## 4. 三种模式

### runSolo（单人）
```
迅捷治愈(有回春/愈合+缺口≥8000) → 树皮(血线) → 野性成长 → 回春/绽放 → 滋养/触 → 愈合
节能时：回春→绽放；无技能→绽放（自己）
```

### runParty（小队）
```
遍历5人：找T/近战；迅捷治愈(直接打断循环) > 树皮 > 野性成长(优先T→近战→掉血最多→自己) > 坦克愈合 > 滋养(掉血) > 坦克回春 > 掉血最多回春 > 挨个回春
节能时：回春→绽放；无目标→T/近战/自己绽放
```

### runRaid（团队）
```
遍历raid1-25/40：
  迅捷治愈 > 树皮（优先循环内）
  血肉成灰→滋养（supportSpecialDebuff）
  野性成长：T1→T2→T3→近战→掉血最多→自己
  坦克回春：T1→T2→T3（无盾）
  坦克愈合：T1→T2→T3（缺口达标，未移动）
  坦克滋养：T1→T2→T3（掉血达标，未移动）→ 掉血最多滋养
  掉血最多回春（无盾检查放宽）
  TOC debuff 目标→滋养
  挨个回春（含满血，带盾检查）
节能时：回春→绽放；无目标→T/近战/自己绽放
```
