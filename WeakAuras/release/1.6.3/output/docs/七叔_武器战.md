**宏捆绑体系**（核心机制）：
- `S_HS.*` = `-100000 - ID`：**捆绑英勇打击**的宏（高怒单体）— `/cast 技能\n/cast !英勇打击`

## 4. 辅助函数

| 函数 | 说明 |
|------|------|
| `getSwingRemain()` | 平砍剩余时间（基于 SwingTimer 追踪） |
| `getNearbyCount()` | 5 码内敌人数量（去重 GUID） |
| `getHPPercent(unit)` | 目标血量百分比 |
| `hasFear()` | 是否被恐惧（LossOfControl 检测 FEAR） |

**SwingTimer 平砍监视器**：帧监听平砍命中/施法暂停，OnUpdate 累计暂停时间；`COMBAT_LOG_EVENT_UNFILTERED`（平砍重置 + 利刃风暴激活）、`UNIT_SPELLCAST_START/STOP/INTERRUPTED`（暂停/恢复）、`PLAYER_REGEN_ENABLED`（重置）。

## 5. 核心输出逻辑 APLCallback_ArmsWarrior（优先级从高到低）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | 狂暴之怒CD好 && 被恐惧 | 狂暴之怒 18499 |
| 2 | Boss && 鲁莽CD好 && (脱战 或 战斗中怒气≤10) | 鲁莽 1719（冲锋前起手爆发） |
| 3 | 有目标 && 不在近战范围 && 冲锋在射程 | 冲锋CD好→冲锋；否则怒气≥10且冲锋CD<17且拦截CD好→拦截 |
| 4 | Boss && 英勇投掷CD好 && 不在近战范围 | 英勇投掷 57755 |
| 5 | 怒气<75 && 血性狂暴CD好 | 血性狂暴 2687 |
| 6 | 敌对玩家 && 近战范围 && 目标无断筋 && 断筋CD好 | 断筋 1715（PvP） |
| 7 | Boss && 碎裂投掷CD好 && 目标无破甲 && 怒气≥25 | 碎裂投掷 64382 |
| 8 | Boss && 手套CD好 && 近战范围 | -112（手套+炸弹） |
| 9 | 脱战 或 无目标 | 平砍 6603 |
| 10 | 利刃风暴持续中（<6s） | 利刃风暴 46924 |
| 11 | 目标无撕裂 && 撕裂CD好 | 撕裂（autoSelect） |
| 12 | 致死打击CD好 | 致死打击（autoSelect） |
| 13 | 压制CD好 && 有压制触发buff | 压制（autoSelect） |
| 14 | 斩杀CD好 && 致死CD>1s && 怒气>65 && (有猝死 或 目标<20%且死亡时间紧迫) | 斩杀（autoSelect） |
| 15 | AOE模式 && 怒气≥30 && 横扫CD好 | 横扫攻击 |
| 16 | AOE模式 && 怒气≥55 && 敌人>5 && 雷霆CD好 | 雷霆一击 |
| 17 | AutoBladestorm && 利刃风暴CD好 && 目标死亡时间>3 | 有嗜血/英勇buff→爆发风暴宏；否则→利刃风暴 |
| 18 | 致死CD>1s && 怒气≥25 && 猛击CD好 && 破坏能手<3层 && (压制buff≤0或≥5s) | 猛击（autoSelect） |
| 19 | 兜底 | autoSelect(6603)（高怒绑英勇/顺劈，低怒白刀） |

**autoSelectSpell 机制**：怒气≥75 时返回 -100000-ID（绑英勇）或 -200000-ID（绑顺劈，AOE模式）；否则返回原始 ID（白刀）。

**AOE 模式切换**：`config.SmartAOE` 开启且 5 码内≥2 敌人 → CleaveMode。
