**ID 偏移**（核心机制）：
- `CLIP_OFFSET = 100000`：**断鞭版**（`/cast [nochanneling:暗言术：渊] 技能` — 可打断鞭笞，不打断渊）
- `FOCUS_OFFSET = 200000`：**焦点版**（`/cast [target=focus] 技能`）
- 可组合：`技能 + FOCUS_OFFSET + CLIP_OFFSET`（焦点断鞭版）

**特殊宏**：
- `-10000`：/target focus（渊引导中切焦点）
- `-20000`：/targetlasttarget（切回主目标）
- `-30000`：全爆发宏（手套+饰品+种族）；`-30000 + CLIP_OFFSET` 断鞭版

## 6. 二段鞭（断鞭）管理 APLCallback_ShadowPriest

```
spell = DecidePriority()
若 spell 是 鞭笞 → 直接返回（引导技能不打断）
若 spell 是 灭 且 有慈悲 + 专注CD好 → 替换为心灵专注宏
记录 HighPrioSinceTime（非鞭推荐出现时间）
ClipDecision() 判定：
  - 非"clip" → 直接返回原技能
  - "clip"（已过2跳）→ 若推荐时间 ≤ 第2跳出伤时间 → 返回 CLIP_OFFSET 断鞭版
```

**核心**：只有第 2 跳之前推荐的技能才允许断鞭，避免损失伤害。
