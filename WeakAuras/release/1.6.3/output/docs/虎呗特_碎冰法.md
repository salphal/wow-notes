## 5. 核心输出逻辑 APLCallback（优先级从高到低）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | 脱战 && 无法力青玉 | 制造法力宝石 42985 |
| 2 | 无水元素 && 水元素CD好 && 寒冰指≠1层 | 召唤水元素 31687 |
| 3 | 补智力/光辉（<300s && CD好 && 脱战） | 奥术智慧 42995 |
| 4 | **补熔岩护甲**：战斗中无buff；脱战<300s | 熔岩护甲 43046 |
| 5 | **镜像**：有疲劳/饱足 debuff && Boss战 && autoJingxiang | 镜像 55342 |
| 6 | **种族/爆发**（冰冷血脉CD>0 && 有目标）：Boss战→狮心爆发宏（CD好+autoFirstBurst）；巨魔狂暴+饱足<560s→巨魔爆发宏 | 9999997 / 9999996 |
| 7 | **冰冷血脉**（autoBurst && autoBinglengxuemai && Boss && 战斗中） | 冰冷血脉 12472 |
| 8 | **急速冷却**（autoJisulengque && 冰冷血脉CD>0 && 深冻CD>10 && Boss） | 急速冷却 11958 |
| 9 | **寒冰指≥1层** && (AOE≥2 或 寒冰箭<1s)：深冻CD好→深冻 | 深度冻结 44572 |
| 10 | **冰锥多目标**（碎冰天赋 && Boss级AOE≥2）：冰锥>冰霜新星 | 42931 / 42917 |
| 11 | **寒冰指1层** && 施法中：深冻→火球buff→冰枪(射程≥15 && 长枪天赋 && 寒冰箭≥1.2s)→冰锥(近距 && 碎冰 && ≥1s)→冰霜新星 | 44572/47610/42914/42931/42917 |
| 12 | **无寒冰指** && 施法中：火球buff→霜火之箭；急速<1.2s && 近距 && 碎冰→冰锥 | 47610 / 42931 |
| 13 | 兜底 | 寒冰箭 42842 |

**关键机制**：
- 寒冰指(74396)层数通过 `getBuffRankByPlayer` 获取（1/2层）
- 火球！buff(57761) → 瞬发霜火之箭
- 天赋检测：长枪(3-32) 决定冰枪射程条件、碎冰(3-30) 决定冰锥/新星使用
