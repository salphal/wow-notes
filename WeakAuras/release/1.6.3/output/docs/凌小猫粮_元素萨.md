## 5. 核心输出逻辑 APLCallback_ElementalShaman（优先级从高到低）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | **战前**：武器无火舌附魔或剩余<10分钟 | 火舌武器 58790 |
| 2 | **战前**：水盾≤450s | 水之护盾 57960 |
| 3 | **战前**：图腾不齐 | 元素的召唤 66842 |
| 4 | **战前**：预读 | 闪电箭 49238 |
| 5 | 无有效目标 | 平砍 6603 |
| 6 | **爆发**（auto_burst && Boss && 熔岩CD好 && 震击>15s && 任一爆发就绪） | 元素掌握爆发宏 16166 |
| 7 | **雷霆风暴**（auto_thunderstorm && 蓝<60% && CD好） | 雷霆风暴 59159（回蓝） |
| 8 | **水盾**（auto_watershield && 无盾 && 非爆发期） | 水之护盾 57960 |
| 9 | **打断**（auto_windshear && 目标施法 && CD好） | 风剪 57994 |
| 10 | **烈焰震击**：目标无震击 && CD好 | 烈焰震击 49233 |
| 11 | **提前补震击**：熔岩CD≤1s && 震击剩余撑不到 && 震击CD好 | 烈焰震击 49233 |
| 12 | **熔岩爆裂**：CD好 && 震击剩余>熔岩施法时间 | 熔岩爆裂 60043 |
| 13 | **闪电链**（smart_chainlightning && 30码内≥2敌人 && CD好） | 闪电链 49271 |
| 14 | 兜底填充 | 闪电箭 49238 |
