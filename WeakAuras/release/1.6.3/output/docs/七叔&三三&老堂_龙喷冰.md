## 6. 事件监听

**Manager 帧**监听：
- `COMBAT_LOG_EVENT_UNFILTERED`：自己传染施法成功 → 记录 `LastPestilenceTime`
- `PLAYER_REGEN_DISABLED`：检测骨疽天赋(51459等)/蔓延天赋(49562等)/雕文(63334疾病/58715冰打)
- `PLAYER_REGEN_ENABLED`：重置 AOE/传染时间记录
