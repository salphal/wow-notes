# 阿尔法_火法 输出逻辑文档

> aura id: 阿尔法_火法 | uid: a1phaFireMage | regionType: empty
> 火法一键 APL - 泰坦重铸时光服 | 作者：阿尔法
> 特性：法术连击瞬发炎爆 > 灼烧debuff保持 > 活动炸弹保持（多目标自动切换）> 燃烧爆发 > 火球术填充

## 1. 文件结构

| 代码块 | 作用 |
|--------|------|
| `actions.init 自定义代码` | 全部逻辑：技能表 + ActionList + 辅助函数 + APLCallback |
| `actions.init 加载时自定义代码` | 版本检查 + `VF_registerAPL(aura_env)` |

入口检查：`if(WOW_PROJECT_ID ~= WOW_PROJECT_WRATH_CLASSIC) then return end`（非 WLK 退出），全局防重入 `APL_FIRE_MAGE_ALPHA`。

## 5. 核心输出逻辑 APLCallback（优先级从高到低）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | 脱战 && 无法力青玉 | 制造法力宝石 42985 |
| 2 | 脱战 && 智力<300s && CD好 | 奥术智慧 42995 |
| 3 | **补熔岩护甲**：战斗中无buff；脱战<300s | 熔岩护甲 43046 |
| 4 | **镜像**：有疲劳/饱足 debuff && Boss战 && autoJingxiang | 镜像 55342 |
| 5 | **爆发宏**（autoFirstBurst && Boss战 && 燃烧CD好 && 目标死亡>20s && 任一爆发就绪） | 法师爆发宏 9999997 |
| 6 | **巨魔爆发**（autoFirstBurst && 狂暴CD好 && 饱足<560s） | 巨魔爆发宏 9999996 |
| 7 | **打断**（autoInterrupt && 目标施法可断） | 法术反制 47528 |
| 8 | **法术连击触发 → 瞬发炎爆**（buff>0 && 炎爆CD好） | 炎爆术 42833 |
| 9 | **保持灼烧**（目标灼烧debuff≤4s && CD好 && 未移动） | 灼烧 42873（5%暴击） |
| 10 | **活动炸弹**（目标炸弹debuff≤4s && CD好 && 目标死亡>8s） | 活动炸弹 55360 |
| 11 | **多目标活动炸弹**（autoMultiBomb && ≥2敌人 && 炸弹CD好 && 未移动）：扫描 30 码内 nameplate，找无炸弹的目标 → `TargetUnit` 切目标后上炸弹 | 活动炸弹 55360（自动切目标） |
| 12 | **AOE烈焰风暴**（≥3敌人 && CD好 && 未移动 && 蓝>30%） | 烈焰风暴 42826 |
| 13 | **移动中**：冲击波CD好→冲击波；龙息CD好→龙息；否则**等待（6603）** | 42859/42840/6603 |
| 14 | **火球术填充**（CD好 && 有目标） | 火球术 42891 |
| 15 | 兜底 | 火球术 42891 |

## 6. 修改指引

| 想改什么 | 改哪里 |
|----------|--------|
| 灼烧刷新阈值 | §5 第 9 条 `zhuoshaoDeBuff <= 4` |
| 活动炸弹刷新阈值 | §5 第 10 条 `<= 4` + `TargetDeadTime > 8` |
| 多目标炸弹开关 | `config.autoMultiBomb`（§5 第 11 条，默认关） |
| 多目标炸弹距离 | §5 第 11 条 `WeakAuras.CheckRange(unitid, 30, "<=")` |
| AOE 触发 | §5 第 12 条 `AOECount >= 3` |
| 爆发条件 | §5 第 5 条（Boss+死亡>20s+燃烧CD好） |
| 法术连击优先级 | §5 第 8 条（不可低于灼烧/炸弹） |
| 移动等待行为 | §5 第 13 条（无瞬发返回 6603，避免移动读条） |
| 爆发宏内容 | 9999997/9999996 宏 |
