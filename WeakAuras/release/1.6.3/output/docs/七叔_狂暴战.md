## 5. 核心输出逻辑 APLCallback_FuryWarrior（优先级从高到低）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | 脱战 | 重置 dwUsed，返回平砍 |
| 2 | 无目标/目标死亡 | 平砍 6603 |
| 3 | 非狂暴姿态 | 切狂暴姿态 2458 |
| 4 | 怒气<75 && 血性狂暴CD好 | 血性狂暴 2687 |
| 5 | 狂暴之怒CD好 && 被恐惧 | 狂暴之怒 18499 |
| 6 | 拦截CD好 && 怒气≥10 && 不在近战范围 && 拦截在射程 | 拦截 20252 |
| 7 | Boss && 英勇投掷CD好 && 不在近战范围 | 英勇投掷 57755 |
| 8 | Boss && 死亡之愿CD好 && 未用过 && (有嗜血或英勇buff) | 爆发宏 9999998 |
| 9 | Boss && 碎裂投掷CD好 && 目标无破甲 && 怒气≥25 | 碎裂投掷 64382 |
| 10 | Boss && 已用过死亡之愿 && 鲁莽CD好 | 鲁莽 1719 |
| 11 | Boss && 已用过死亡之愿 && 手套CD好 && 近战范围 | -112 |
| 12 | 嗜血CD好 | 嗜血（autoSelect） |
| 13 | 旋风斩CD好 && 嗜血CD>0 | 旋风斩（autoSelect） |
| 14 | 血涌buff && 嗜血/旋风CD中 | 猛击（autoSelect） |
| 15 | 目标<20% && 无血涌 && 嗜血/旋风CD≥1.5s && 怒气≥60 | 斩杀（autoSelect） |
| 16 | 怒气<30 && 平砍<0.3s && 正在英勇/顺劈 | -6603（取消附加技） |
| 17 | 怒气≥12 && 单体 && 平砍≥0.3s && 未在英勇 | 英勇打击 |
| 18 | 怒气≥20 && AOE && 平砍≥0.3s && 未在顺劈 | 顺劈斩 |
| 19 | 兜底 | 平砍 6603 |

**autoSelectSpell**：怒气≥45 时返回捆绑宏（AOE 模式绑顺劈 -200000-ID，单体绑英勇 -100000-ID）；否则原始 ID。

**AOE 判定**：8 码内敌人≥2 → CleaveMode。
