## 4. 熔岩图腾追踪（核心复杂逻辑）

**TotemState** 通过战斗日志追踪熔岩图腾的放置时间、目标、伤害跳数：
- `SPELL_SUMMON` 熔岩图腾 → 记录 GUID/时间/目标
- 图腾伤害事件 → 记录 `lastTickAny`/`lastTickDestGUID`/`lastTickTarget`

**GetTotemNeeds()** 判断是否需要重插熔岩图腾（返回 haveMagma, hasFireElemental, needMagma）：
| 条件 | 动作 |
|------|------|
| 火元素在场 | 禁止重插火系 |
| 无火系图腾 | 必须补插 |
| 火系图腾非熔岩 | 需要重插 |
| 图腾快过期(<2s) | 重插 |
| 图腾 4 秒无任何伤害 | 重插 |
| 转火场景（图腾打小怪目标切BOSS） | 重插 |
| 对当前目标断档（BOSS 3s/小怪 5s） | 重插 |
| 目标切换后从未对新目标造成伤害 | 重插 |

**canFireNova()** 判断火焰新星能否施放：
- 非熔岩图腾（火元素/灼热）→ 可直接施放
- 熔岩图腾：2.5s 内对当前目标造成伤害→可；BOSS 不允许兜底；否则图腾刚放 3s 内目标 5 码内 或 8 码内≥2 敌人→可

**petAttack 机制**：目标切换或超 2.5s 未攻击时，先等待 3 帧（返回 6603）再进入正常循环（让宠物转火）。
