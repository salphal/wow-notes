## 5. 核心输出逻辑 APLCallback（状态机）

### phase = "idle"（脱战准备）
| 条件 | 动作 |
|------|------|
| 无宠物 && 复生CD好 | 亡者复生 46584 |
| 石像鬼CD<10 && 非邪脸 | 切邪灵气 48265 |
| 骨盾CD好 && 骨盾buff≤60s | 白骨之盾 49222 |
| 无目标 或 目标无冰病 | 冰触 49909 |
| 兜底 | 平砍 6603 |

### phase = "opener"（起手）
按 openerTable 顺序执行：
- 冰病已存在则跳过起1（冰触）
- 号角步骤时若CD>1且能量≥60 → 跳到天鬼
- 石像鬼CD中→跳到符武；符武CD中→大军CD中→跳16 否则→12；大军CD中→_armyReplace 替换序列（冰触/暗打/血打×3）
- 天鬼在BOSS+autoBossBurst+能量≥60时插入（nSub==1 时）
- 凋零CD中→填充函数；活分CD中→跳过；切红脸时若已红脸或有强化邪灵气→换血打
- 循环表走完 → phase="normal"

### phase = "normal"（循环）
每轮 nRound(1-4) 的 nSub 步骤：
- 每轮开始检测 `_roundAOE`（usePestilence && 敌人≥pestilenceTargets）
- 步骤技能CD中 → **填充函数 GetFiller**：能量≥55且缠绕CD好→凋零缠绕；能量<90且号角CD好→号角；手套好→手套；否则等待
- 能量≥100 且缠绕CD好 → 泄能凋零缠绕
- 非填充状态 + 手套好 + (天灾/凋零步骤) → 先打手套
- 传染步骤时实时检测 AOE 数量不够 → 换血打
- 邪组狂乱步骤且非Boss → 换成暗影打击

**Miss 处理**：`SPELL_MISSED`/`SWING_MISSED` 且是 MISS/DODGE/PARRY/RESIST → 回退一步（opener>1 或 normal nSub>1），枯萎凋零/血沸/浸血类除外。

## 6. ActionList 构建（动态生成）

- 遍历全部技能 ID 生成 `/cast [nochanneling] 技能\n/startattack\n/petattack\n/cast 爪击` 宏
- 凋零特殊：`[@player,nochanneling]`
- 石像鬼特殊：`/cqs + 种族(石像/血狂) + /use 13/14 + 石像鬼`
- 大军特殊：`/cqs + 狮心/狂暴 + (手套可选) + (速度药水可选) + 亡者大军`
- 复生、手套炸弹宏单独插入
