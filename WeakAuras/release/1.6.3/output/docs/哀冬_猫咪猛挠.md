## 4. 事件监听（智能AOE 核心）

**onCLEUEvent**：
- 自己横扫(62078) 伤害/未命中 → `SwipeCount + 1`；>2 次 → `intoSmartAOE = true`；撕碎/裂伤命中 → 退出 AOE
- 自己施法：横扫施法 → 计数清零；狂暴施法 → `isFirstBerserkDone = true`

**Manager 帧**：OnShow→进猫(改队列窗口200)；OnHide→退出(恢复400)；监听 `COMBAT_LOG_EVENT_UNFILTERED`。
