## 3. 智能 AOE 机制

- 种子（腐蚀之种 47836）命中 >2 次（`SeedHitCount > 2`）→ `intoSmartAOE = true`
- 暗影箭/烧尽命中 → 重置 false
- 施放种子 → 计数清零
