## 5. 核心输出逻辑（三模式）

### runSolo（单人）
```
圣光术(缺口≥4000) → 闪现(缺口≥2000，enableFlashOfLight 决定是否真用闪现)
```

### runParty（小队）
```
找T/近战/道标持有者 → 分类缺口
道标补焦点 → 道标非T时优先奶T(圣光) → 无道标者中缺口最大的圣光 → 道标目标掉血时：奶掉血最多的无道标者(折射) → 奶T/近战/自己
兜底：无道标者缺口最大的 → 预读模式：奶T/近战/自己
```

### runRaid（团队，优先级从高到低）
| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | **焦点道标**（autoBeacon && 无道标或快结束） | 焦点道标 |
| 2 | **血肉成灰特判**（有血肉成灰 && 非道标持有者 && 未移动） | 圣光术 |
| 3 | **坦克圣光**（道标非T && T1/T2/T3 缺口≥4000） | 圣光术 |
| 4 | **大团圣光**（无道标者缺口最大 ≥4000） | 圣光术 |
| 5 | **坦克/近战小光**（缺口≥2000） | 闪现/圣光 |
| 6 | **折射治疗**（道标掉血 && 无道标者任一掉血）：奶掉血最多的无道标者 | 圣光/闪现 |
| 7 | **TOC debuff 预读**（danger debuff 目标） | 圣光/闪现 |
| 8 | **坦克/近战小光兜底** | 圣光/闪现 |
| 9 | **奶自己折射**（道标掉血） | 圣光/闪现 |
| 10 | **血肉成灰=道标持有者** → 奶自己折射给他 | 圣光术 |
| 11 | **正常逻辑**：无道标者缺口最大 | 圣光/闪现（按缺口） |
| 12 | **空闲预读**（enablePreCast && 未移动）：T1→T2→T3→近战→自己 | 圣光/闪现 |

**折射治疗核心思想**：道标目标掉血时，通过治疗其他人来折射给道标目标（圣光术/闪现对道标持有者 100% 复制治疗）。
