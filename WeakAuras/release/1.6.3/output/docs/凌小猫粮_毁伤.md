## 4. 核心输出逻辑（优先级从高到低）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | 脱战 && 无潜行 && 潜行CD好 | 潜行 1784 |
| 2 | **打断**（autoKick && 战斗中 && 能量≥25 && 目标施法可断） | 脚踢 1766 |
| 3 | **转嫁**：转嫁充能 > 当前星 | 转嫁 1282540 |
| 4 | **破甲**（autoExposeArmor && 战斗中 && 近战 && 破甲≤3s）：有星→破甲；无星+能量>55→毁伤攒星 | 8647 / 48666 |
| 5 | **爆发**（战斗中 && Boss && 切割>6s && 近战 && 深毁伤或乱舞条件）：种族/手套/炸弹任一就绪→-300；饰品1/2→13/14（雷纳塔基护符能量<40才用）；能量<40且有茶→-200 | 爆发系 |
| 6 | **剑刃乱舞分支**（isBladeFlurry） | 见下 |
| 7 | **深毁伤分支**（isDeepAssa） | 见下 |
| 8 | **通用**：嫁祸→切割→消失→冷血→毒伤→毁伤→平砍 | 见下 |

### 剑刃乱舞分支（乱舞激活中）
```
切割补星(<1s && ≥1星) → 消失(无灭绝buff && Boss && 非黑名单) → 冷血(4星) → 冷血毒伤连招 → 多目标(≥2)：毒伤宽松(≥2星+35能量) > 毁伤(能量>55)；单目标：毒伤三维决策(CP/能量/毒伤buff剩余) → 毁伤
乱舞就绪（未激活）：确保切割≥17s → 能量≥90开乱舞
```

### 深毁伤分支
```
潜行转嫁切割(潜行 && 切割无 && ≥1星) → 锁喉(潜行 && 无流血 && 能量≥50) → 血之饥渴(战斗中 && 有流血 && <5s) → 割裂(无流血 && 无饥渴buff && ≥2星)
```

### 通用逻辑
```
嫁祸(autoTricksTrade && 组队 && (切割≥1s 或 潜行) && 焦点/目标目标是友军且射程内)
切割(能量>25 && ≤1s && ≥1星)
消失(autoVanish && 战斗中 && 无灭绝 && Boss && 非黑名单 && 能量>60 && 嫁祸CD<8)
冷血(战斗中 && CD好 && 切割>0 && 非潜行 && ≥4星 && Boss)
毒伤(有致命毒 debuff && 近战 && CD好)：CP≤2不打；3星(能量>90 或 70-90且毒伤<0.2s 或 55-69且无毒伤)；4星(>90 或 75-90且<0.5s 或 45-74且无)；5星(>90 或 35-89且<0.5s)
毁伤(近战 && 能量>55 && CD好)：无毒→可打；CP≤2→可打；3星+能量>85+毒伤>0.5s→可打
收尾：CP≤2&&能量>55→毁伤；CP==3&&能量>85→毁伤；否则平砍
```
