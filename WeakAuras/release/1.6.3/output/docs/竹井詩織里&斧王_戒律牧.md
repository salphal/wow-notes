## 4. 辅助函数

| 函数 | 说明 |
|------|------|
| `getUnitRoleType` | 角色判定：最大血量→TANK；有韧buff+血量>1.1倍阈值→TANK；职业判定 MELEE/RANGE |
| `calcUnitHealthDiff` | 真实缺口 = 最大血量 - 当前血量 - 治疗预读（苦修 12000 / 快疗 5000） |
| `spellReady` / `inRange` / `unitHasTOCDebuff` | 同奶萨 |
| 苦修引导锁定 | `isCastingPenance`（PenanceGUID 非空）；**5 秒超时自解锁**修复 |

**虚弱灵魂 debuff**（6788）：有虚弱灵魂或已有盾 → 不可再盾。

## 5. 核心输出逻辑 runRaid（优先级树从高到低）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| L50 | 苦修就绪 && 未锁定 && 目标有血肉成灰(66237) && 未移动 | **苦修** |
| L49 | 苦修就绪 && 未锁定 && 最低血<50% && <阈值 && 未移动 | **苦修**（救命） |
| L48 | 血肉成灰目标 && 未移动 | **快速治疗** |
| L40 | TOC debuff 目标 && 无虚弱灵魂 && 无盾 | **盾** |
| L39 | 愈合就绪 && TOC debuff 目标 && 全团安全(≥50%) && 无愈合无盾 | **愈合祷言** |
| L30 | 无盾最低血<50% && <阈值 | **盾**（危急保命） |
| L29 | 苦修就绪 && 未锁定 && 最低血<阈值 && 未移动 | **苦修**（兜底补缺） |
| L28-PoM | 愈合就绪 && 无愈合无盾 && 血<阈值 | **愈合祷言** |
| L28-Shield | 无盾最低血<阈值 | **盾** |
| L26 | 愈合就绪 && 拉怪坦克 && 全团安全 | **愈合祷言**（坦克） |
| L19 | 最低血<阈值 && 未移动 | **快速治疗**（保底） |
| L20/18/10 | 站街铺盾 | 按 近战→远程→坦克 顺序铺盾 |

**角色优先级**：先保 debuff 目标（血肉成灰 > TOC debuff）→ 危急盾 → 苦修 → 愈合 → 快疗 → 空闲铺盾。
