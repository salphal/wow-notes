## 5. 核心输出逻辑 APLCallback_ProtWarrior（优先级从高到低）

> 回调每次调用返回一个 ActionList 中的动作 ID。**顺序即优先级**——先匹配的先执行。

### 5.0 变量准备
获取：GCD、施法队列窗口、战斗状态、自身血量、怒气、8 码敌人数、是否 Boss 战、目标血量、目标死亡时间、是否近战范围、是否防御姿态；所有技能 CD（减 GCD）、Buff 剩余（盾牌格挡/破釜/盾墙/血性狂暴/复仇激活）、Debuff 剩余（雷霆/挫志/破甲）。

### 5.1 脱战准备（非战斗中）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | 非防御姿态 | 防御姿态 71 |
| 2 | 有可攻击目标 && 目标无雷霆 && 雷霆CD就绪 | 雷霆一击 47502 |
| 3 | 有可攻击目标 && 目标无破甲 && 破甲CD就绪 && 怒≥15 | 破甲 7386 |
| 4 | 英勇投掷CD就绪 | 英勇投掷 57755 |
| 5 | 兜底 | 平砍 6603 |
