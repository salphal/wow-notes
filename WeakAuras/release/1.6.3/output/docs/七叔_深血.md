## 6. 核心输出逻辑 APLCallback_BloodDK（优先级从高到低）

| 优先级 | 条件 | 动作 |
|--------|------|------|
| 1 | 脱战 | 重置起手序列；有可攻击目标→冰触提示；否则平砍 |
| 2 | 战斗中无有效目标 | 平砍 6603 |
| 3 | **BOSS起手序列**（冰脸+BOSS+未完成） | 按 openerSQ 依次执行 |
| 4 | **传染**：AOE场景(≥2敌人)任一敌人疾病<4s，或单体双病<3s且有疾病雕文 | 传染 50842 |
| 5 | **枯萎凋零**：有啜血buff + 双病齐全 + CD好 | 枯萎凋零 49938 |
| 6 | **血沸**：凋零CD<2s + 双病齐全 + 无啜血 | 血液沸腾 49941（触发啜血） |
| 7 | **补双病**：缺冰病→冰触；缺血病→暗打 | 49909 / 49921 |
| 8 | **心打/血沸**：双病齐全+剩余≥4s | AOE(≥3敌人)→血沸；单体→心脏打击 |
| 9 | **灵打**：心打/血沸CD中 + 冰暗符文可用 + 双病≥4s | 灵界打击 49924 |
| 10 | **凋零兜底**：CD好 | 枯萎凋零 49938 |
| 11 | **凋零缠绕**：凋零真CD≥2s + 能量达标（冰脸80/其他60） | 凋零缠绕 49895 |
| 12 | **血沸填充**：CD好 | 血液沸腾 49941 |
| 13 | **寒冬号角**：CD好 + 无号角buff + 任一疾病>2s | 寒冬号角 57623 |
| 14 | 兜底 | 平砍 6603 |
